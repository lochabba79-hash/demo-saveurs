# Demo Safran — مطعم الزعفران (concept project)
> Fictional business. All names, dishes, prices, phone numbers invented for portfolio/outreach.

## Design read
Editorial food story for design-conscious diners, minimalist-luxe language, native CSS + scroll reveals + sticky narrative. No frameworks, no build step.

## Run
`npx serve .` → http://localhost:3000 (file:// works except GLB-like fetches — none here; all local).

## Sections
Hero (parallax) → marquee → story + stats → signature break → sticky fire narrative →
menu → gallery strip → difference + testimonial → booking → footer.
